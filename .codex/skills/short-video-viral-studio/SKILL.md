# short-video-viral-studio

用于 Codex 项目内的**可调用 Skill**，不是独立智能体。它把「爆款解析 → 自拍素材匹配 → 新脚本/AI 分镜 → AI 片段生成 → 并线剪辑 → 最终审计」串成一条可分阶段调用、也可端到端调用的短视频生产流水线。

## 适用场景

- 用户提供短视频平台链接，想复用原视频的爆款公式做新片
- 用户提供文案文本，想按爆款结构生成新脚本和分镜
- 用户必须提供自拍素材，并要求自拍素材真实进入成片

## 必选输入

1. `selfie_assets`：用户自拍素材，**必填**
2. `source_video_url` 或 `source_text`：二选一，作为爆款解析来源

如果没有自拍素材，Skill 必须中止，并明确提示缺少必选输入；不能跳过素材匹配直接生成最终片。

## 核心执行要求

### 1. 爆款公式解析

提取并结构化输出：

- 亮点 / 爆点
- 开头钩子
- 节奏结构
- 情绪曲线
- 可复用爆款公式

要求复用的是**结构、节奏、钩子与转化逻辑**，不是简单改写原内容。

### 2. 自拍素材强制输入与匹配

对用户自拍素材进行镜头级分析，并输出：

- 可用镜头清单
- 时长、画幅、风格、人物状态
- 自拍素材到爆款结构阶段的映射关系
- 不匹配时的 fallback 方案

最终成片必须保留用户自拍素材，不能被纯 AI 片段完全替代。

### 3. 新脚本与 AI 分镜

基于爆款公式和自拍素材匹配结果生成：

- 新视频脚本
- 分镜列表
- 每个分镜对应的 AI 视频提示词
- 每个分镜对应的自拍素材/AI 片段来源说明

### 4. 付费 API gating

调用外部付费视频、语音或媒体生成 API 前，必须先确认：

- 用户已显式同意调用付费 API
- 所需密钥和计费前提已具备

如果未获批准，Skill 只能停留在脚本、分镜、镜头映射和待执行计划层，不能默认触发付费生成。

### 5. 并线剪辑

把 AI 片段与用户自拍素材并线编排，输出：

- 镜头时间线
- 自拍素材插入点
- AI 片段插入点
- 旁白/字幕/转场建议

并线剪辑应以自拍素材为真实主体，AI 片段只补足缺失镜头或增强表达。

### 6. 最终审计与来源/约束溯源

最终交付前必须做审计，确认：

- 爆款公式是否被完整复用
- 自拍素材是否真实出现在成片中
- 每个镜头是否保留来源追踪
- 是否违反用户素材约束、人物一致性约束或付费 API 约束

所有阶段输出都应带有 `source_trace` 与 `constraint_trace`，便于回溯。

## 推荐调用方式

```text
使用 $short-video-viral-studio 基于参考视频和我的自拍素材生成短视频
```

## 阶段化输出

1. 爆款解析报告
2. 自拍素材匹配方案
3. 新脚本与 AI 分镜
4. AI 视频片段生成计划或结果
5. 并线剪辑方案
6. 最终审计结果

详细输出结构见 `references/output-schema.md`。
